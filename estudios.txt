# ESTUDIOS DE AXIA
# Este archivo alimenta la sección "Estudios" de la página.
#
# CÓMO AGREGAR UN ESTUDIO:
# 1. Copiá uno de los bloques de abajo (desde "Título:" hasta la línea "---").
# 2. Pegalo arriba de todo (el primero de la lista se muestra primero).
# 3. Cambiá los textos que están después de los dos puntos.
# 4. Las líneas en inglés (Title, Sector EN, Summary) son opcionales:
#    si las dejás vacías, en inglés se muestra el texto en español.
#
# IMAGEN DEL ESTUDIO (opcional):
# - Dejá la imagen en la carpeta "portadas" del repositorio, cuadrada y en webp
#   o jpg, de unos 900 por 900 píxeles, y agregá una línea "Imagen:" con el
#   nombre del archivo.  Ejemplo:  Imagen: langostino-argentino.webp
# - Aparece en la página del estudio, al lado del resumen, y es la que se ve
#   cuando el enlace se comparte por LinkedIn o WhatsApp.
# - Si no ponés ninguna, la página sale sin imagen: no se rompe nada.
#
# ESTUDIOS QUE SE ACTUALIZAN SEGUIDO (la canasta semanal, por ejemplo):
# - Agregale una línea "Relevamiento:" con la fecha del último relevamiento,
#   en año-mes-día.  Ejemplo:  Relevamiento: 2026-10-23
# - En la web aparece "Último relevamiento: 23 de octubre de 2026", debajo del
#   rubro, y en inglés "Latest survey: 23 October 2026": la fecha se escribe
#   una sola vez acá y el sitio la traduce sola.
# - Si no es una fecha exacta, escribí el texto que quieras: sale tal cual.
# - Cambiá esta fecha cada vez que subas un informe nuevo, y volvé a correr
#   _automatizacion/publicaciones/generar.py para que la página del estudio
#   quede con la misma fecha que la portada.
#
# VISOR PROTEGIDO (recomendado para publicar un estudio completo):
# - Dejá el PDF en la carpeta "Estudios" de tu computadora y agregalo a la
#   lista ESTUDIOS de Estudios/build-visor.py. Después corré:  py build-visor.py
# - Eso genera una carpeta dentro de "visor" con las páginas convertidas a
#   imagen y cifradas. El PDF original NO se sube nunca.
# - En el bloque del estudio agregá una línea "Visor:" con el nombre de esa
#   carpeta.  Ejemplo:  Visor: langostino-argentino
# - En la web aparece el botón "Ver el estudio online": se lee en pantalla,
#   pero no se puede descargar, imprimir, copiar texto ni guardar las imágenes.
#
# ARCHIVOS CON RESULTADOS (opcional, queda descargable sin protección):
# - Subí el archivo a la carpeta "estudios" del repositorio en GitHub.
# - En el bloque del estudio agregá una línea "Archivo:" con el nombre exacto.
#   Ejemplo:  Archivo: resultados-pesca-2025.pdf
# - Para más de un archivo, separalos con punto y coma:
#   Archivo: informe.pdf; anexo-datos.xlsx
# - Si tenés versión en inglés:  Archivo EN: results-fisheries-2025.pdf
# - Usá nombres sin espacios, sin tildes ni ñ (usá guiones: informe-final.pdf).
# - Tamaño máximo por archivo al subirlo desde la web de GitHub: 25 MB.
# - La carpeta del repositorio tiene que llamarse "estudios", todo en minúscula.
# - OJO: todo lo que se publique con "Archivo:" queda público, se puede
#   descargar, imprimir y copiar. Para estudios propios usá "Visor:".
#
# Las líneas que empiezan con # no se muestran en la web.
# No nombres clientes sin su permiso.
